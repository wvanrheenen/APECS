# simPed
a pedigree simulation for complex and Mendelian traits

## Setup
This is a list of required R packages:
data.table
tidyverse
MASS
mvnfast
pedtools
ribd
RColorBrewer
```
packages = c("data.table", "tidyverse", "MASS", "mvnfast", "pedtools", "ribd", "RcolorBrewer")
install.packages(packages)
```
